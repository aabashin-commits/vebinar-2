# Лендинг вебинара «Хорошист не прошёл в 10 класс»

Одностраничный лендинг под вебинар для родителей девятиклассников, не прошедших
по конкурсу в профильные 10-е классы. Цель страницы — собрать регистрации на эфир
и привести в 10 класс «Моей школы LS», где приём идёт без конкурса.

Чистые HTML + CSS + vanilla JS: ни сборщика, ни npm, ни фреймворков. Точка входа —
`index.html`. Папка автономная: свои `assets/`, `css/`, `js/`, никаких ссылок
на соседние проекты.

## Как запустить локально

Открывать файл напрямую нельзя — шрифты упрутся в CORS. Поднимаем сервер:

```sh
python3 -m http.server 8766
# http://localhost:8766/index.html
```

Для отладки правок CSS/JS лучше сервер с `Cache-Control: no-store` —
готовая команда в [CLAUDE.md](CLAUDE.md), раздел «Проверка».

## Состояние проекта

Лендинг рабочий: кнопки живые, вёрстка не разъезжается, таймер тикает.
Пять вещей ждут вводных от клиента — дата эфира, ID отдельной CRM-формы Битрикс24,
сверка юридических формулировок, лицей прикрепления, цифры по конкурсу.
Список с точными местами правки — в [CLAUDE.md](CLAUDE.md).

⚠️ Отдельного git-репозитория у папки нет — `.git` вебинара 1 намеренно не копировался.
